The vignette experiment was administered using a custom open-source web application developed for blocked vignette designs. The application assigns respondents to vignette sets using quota-randomisation, randomises vignette order within blocks, and records item responses, response times, and attention-check outcomes. Vignette texts and blocked designs were generated prior to data collection using R, and the web application dynamically loaded vignette sets from the file system at runtime. Data were stored in a PostgreSQL database and exported in analysis-ready format. The full source code and documentation are publicly available at: [GitHub URL].
